# 개발 과정

2024년 3월부터 6월까지 공간 자료 구축·자료 조사 → 탐색 → 군집·최단거리 → 거리 분포·가중치 → 입지 확인 순서로 진행함. 기간은 각 단계 작업 파일의 수정일 기준임.

## 단계별 흐름

| 단계 | 기간 | 무엇을, 왜 바꿨나 |
|---|---|---|
| 자료 조사·현황 분석 | 2024.04~06 | 환경부·한국환경공단의 바이오가스화 정책과 시설 현황 자료를 모으고, 폐자원 에너지 반입량·생산량을 R로 시각화함. 바이오가스 생산량이 적고 가축분뇨 발생이 늘어나는 지역에 신규 시설 수요가 있다고 보고 강원도를 분석 대상으로 정함. |
| 공간 자료 구축 | 2024.03~05 | QGIS에서 강원도 1km 인구 격자와 도로 노드·링크 자료를 정리함. 입지 제외 조건(보호시설·인구 밀집)과 도로망 분석의 기반 자료임. |
| 보호시설·교차로 노드 탐색 (v0.1) | 2024.05.20 | 제1종 보호시설 위치와 교차로 노드를 지도로 확인하고, 시설 주소를 지오코딩해 위치를 표시함. 최종 격자 제외는 QGIS에서 수행함. |
| 도로망 최단거리 (v1.0) | 2024.05.20~28 | 직선거리 대신 실제 운반 경로 길이를 쓰기 위해 OSMnx로 도로망을 만들고 시설별 최근접 노드와 시설 간 최단거리(다익스트라)를 구함. 통합 시설은 2종 이상의 폐자원을 처리하므로 서로 다른 유형의 시설 쌍만 비교하고, 기존 바이오가스화 시설과 가까운 쌍은 제외함. |
| 위치 기반 군집화 (v1.0) | 2024.05.27 | 강원도는 태백산맥을 경계로 영동·영서 생활권이 나뉘므로 둘을 분리하고, 행정구역보다 지리적 근접성을 반영하도록 시설 좌표에 k-means를 적용함(영서 4개, 영동 3개). 이후 최단거리는 군집 안에서 계산함. |
| 거리 분포 분석 (v0.2 → v0.3) | 2024.05.29 | 처음에는 폐기물 시설과 가장 가까운 기존 바이오가스화 시설의 거리 분포만 봄. 이어서 안전성(119안전센터, 화재·폭발 위험 대응)과 지속성(가축사육업, 바이오가스 잠재량의 86%가 가축분뇨)을 변수로 추가해 세 가지 거리 분포를 비교함. 파일 이름은 "회귀분석"이지만 회귀 모형은 사용하지 않았음. |
| 버퍼·가중치 (v1.0) | 2024.06.02 | 가축사육업·119안전센터 거리 분포의 25% 분위수(12.54km, 7.35km)를 반올림해 평균한 10km를 버퍼로 정함. 시설 쌍 중심점 반경 10km 안의 가축사육업·119안전센터 비율과 거리 가중치를 더해 군집별 순위를 매김. |
| 입지 확인·시각화 (v1.0) | 2024.06.02~10 | QGIS 1km 격자에서 고압가스 안전관리법 기준 제1·2종 보호시설과 산·국립공원을 제외해 철원군 오지리·군탄리, 인제군 월학리, 삼척시 상덕리를 후보로 확인함. 영동 군집 1·2의 결과가 기존 시설 위치와 일치하는지 지도로 비교하고 보고서·발표 그림을 만듦. |
