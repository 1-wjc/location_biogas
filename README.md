# 최단거리 알고리즘을 활용한 유기성 폐자원 통합 바이오가스화 시설 최적 입지 선정

강원특별자치도의 유기성 폐자원 시설(하수·하수찌꺼기·음식물류폐기물·가축분뇨) 사이의 **도로망 최단거리**를 구하고, 안전성(119안전센터)과 지속성(가축사육업)을 가중치로 반영해 통합 바이오가스화 시설의 입지 후보를 제안한 분석.

- **구분 :** 2024 환경데이터 활용 및 분석 공모전 · 환경데이터 분석 부문(직접분석 보고서)
- **기간 :** 2024.04.22 ~ 2024.06.03
- **팀 :** 4인 (OSMnx 도로망 최단거리, k-means 위치 군집화, R 시각화)
- **성과 :** 강원도 입지 후보 4곳 도출, 기존 통합 바이오가스화 시설 2곳과 위치 일치
- **기술 :** pandas, OSMnx, NetworkX, GeoPandas, folium, ggplot2, sf, leaflet, QGIS

## 배경과 문제

- 2050년까지 바이오가스 의무생산 목표가 정해졌고, 통합 바이오가스화 시설 설치 사업이 공모 방식에서 직접 지정 방식으로 바뀌어 근거 있는 입지 기준 필요.
- 폐자원 운반 차량의 이동거리를 줄이면 운반 중 이산화탄소 배출도 감소 가능.
- 통합 바이오가스화 시설은 유기성 폐자원 2종 이상을 한 시설에서 처리하므로, 서로 다른 유형의 시설 사이 거리가 핵심 기준.

공공데이터 15종(환경부, 한국환경공단, 자원순환정보시스템, 행정안전부, 소방청, 공공데이터포털, 국토통계)을 사용했고, 강원도 추출·위경도 정리·중복·이상치·결측 제거 후 시설 406개를 분석.

## 접근 방법

1. **지역 선정 :** 바이오가스 생산량이 적은 도(전남·충북·경북·강원) 중, 유기성 폐자원의 약 80%를 차지하는 가축분뇨 발생이 늘고 있는 강원도(2020년 대비 2022년 약 +15%)를 선정.
2. **위치 기반 군집화 :** 태백산맥을 기준으로 영동·영서를 나누고, 시설 좌표에 k-means를 적용(영서 4개, 영동 3개 군집).
3. **최단거리 산출 :** OSMnx로 강원도 도로망을 불러와 각 시설의 최근접 노드를 찾고, `shortest_path`(다익스트라)로 군집 안의 서로 다른 유형 시설 간 최단거리 산출. 거리 순으로 정렬하고 두 시설의 중심점을 계산.
4. **버퍼 설정 :** 기존 바이오가스화 시설에서 가장 가까운 가축사육업·119안전센터까지의 거리 분포를 보고, 25% 분위수(12.54km, 7.35km)를 반올림해 평균한 **10km**를 버퍼로 설정.
5. **가중치 :** 중심점 반경 10km 안의 가축사육업 비율과 119안전센터 비율에, 군집 최대거리를 시설 간 최단거리로 나눈 거리 가중치를 합산.
6. **입지 분석 :** QGIS 1km 격자에서 고압가스 안전관리법 기준 제1종 보호시설(학교·사회복지시설·의료시설), 인구 밀집 지역(제2종), 산·국립공원 격자를 제외.

## 결과

- **입지 후보 :** 철원군 오지리·군탄리(영서), 인제군 월학리(영서), 삼척시 상덕리(영동)
- **모델 적합성 확인 :** 영동 군집 1(속초시)·2(강릉시)에서 모델이 고른 위치가 기존 통합 바이오가스화 시설과 일치.
- 시설 간 최단거리 예시 : 철원군 하수처리시설(갈말) → 가축분뇨처리시설(철원) 1,458.6m
- 군집별 최단거리·중심점과 가중치 결과는 `results/`에 정리. 가중치 계산과 QGIS 격자 분석은 코드 없이 결과 파일과 보고서 그림으로만 보존.

```powershell
pip install -r requirements.txt
Rscript install_packages.R

Rscript code/01_region_status.R
Rscript code/02_geocoding_leaflet.R
Rscript code/03_kmeans_cluster.R            # 영동·영서 구분 파일과 군집 결과를 data/에 저장
jupyter nbconvert --to notebook --execute code/02_facility_maps.ipynb code/05_distance_distribution.ipynb code/04_osmnx_nearest_nodes.ipynb code/04_shortest_path.ipynb code/04_cluster_shortest_path.ipynb
```

- OSMnx는 실행할 때 OpenStreetMap에서 강원도 도로망을 내려받고 `code/cache/`에 저장. 원래 분석과 같은 OSMnx 1.9를 쓰고, 2024년 5월 작업 당시의 응답 캐시로 실행해 최근접 노드 135개가 원래 결과와 모두 같은 것 확인. 지금 내려받는 도로망은 이후 바뀐 도로가 반영되어 결과에 약간의 차이 발생 가능.
- 최단거리 노트북은 강원도 전체 도로망(약 53만 노드)에서 반복 계산하므로 실행 시간이 김.
- `04_shortest_path.ipynb`의 셀 2개(구버전 OSMnx 함수 `get_nearest_node` 사용 셀, 다른 곳에서 붙여 넣은 지도 조각 셀)는 원래 작업 당시에도 실패했던 셀로, 기록을 위해 그대로 유지. 나머지 셀과 다른 코드는 실행 확인.
- 중간 파일과 지도는 `data/`, R 그래프는 `Rplots.pdf`, 실행한 노트북은 `code/*.nbconvert.ipynb`로 저장.

## 배운 점

- **버퍼 기준은 민감도 확인이 필요함.** 10km는 두 거리 분포의 25% 분위수 평균임. 반경을 바꿨을 때 결과가 얼마나 달라지는지 확인해야 함.
- **가중치 척도를 맞춰야 함.** 시설 수 비율(0.0x 수준)과 거리 가중치(1 이상)의 크기가 달라 거리 항이 순위를 주로 결정함. 항목별 정규화와 가중치 근거가 필요함.
- **용어를 정확히 써야 함.** "공간 자기상관"으로 부른 분석은 최근접 거리 분포 분석이며, Moran's I 같은 공간 통계와 구분해야 함.
- **재현 가능한 순서로 남겨야 함.** 줄 단위 대화형 실행으로 작업해 순서·경로가 흐트러진 부분을 정리 단계에서 바로잡음.

## 팀과 역할

4인 팀으로 진행. 본인은 OSMnx 도로망 기반 시설 간 최단거리 산출, 영동·영서 k-means 위치 군집화, R을 이용한 현황 시각화를 담당.

## 개발 과정

자료 조사·현황 분석 → QGIS 공간 자료 구축 → 보호시설·교차로 노드 탐색(v0.1) → 거리 분포 분석(v0.2~v0.3) → 군집·최단거리·버퍼·가중치(v1.0) → 입지 확인 순서로 진행. 단계별 변화와 이유는 [docs/HISTORY.md](docs/HISTORY.md)에 정리.
